# 02 Content 设计一致性退回：修改前差异表

核对基线：02 `e14a7b5`（实现 `22f48d2`）；对照固定原稿 `docs/ui/08-admin-v2/index.html`、`approved-fragment.html` 与四张 screenshots。原技术测试保留，撤回用功能通过推断设计一致的结论。本表先于本轮修改记录。

| 页面/状态 | 原稿 | 当前偏差 | 02 修正范围 |
|---|---|---|---|
| 全局视觉 | 深墨色主按钮、橙色文字动作、灰色分割、紧凑标题间距 | 模块旧 CSS 对所有按钮/标签覆蓝，重复说明占位过大 | 删除旧全局覆盖；使用共享按钮/表单/标签与颜色变量，只增内容专属排布 |
| 片库 | 独立列表页，搜索/状态筛选，剧目/状态/媒体就绪/公开数/管理表格 | 文本行、片库折叠、详情/新建表单常驻 | 表格与筛选；新建弹窗；管理进入独立单剧区域 |
| 单剧外框 | 面包屑返回、剧名/真实总集数/就绪/公开摘要、预览、五标签 | 一级导航、片库、新剧表单与详情混在一起 | 顶层列表与单剧互斥显示；子页名按基本资料/授权与试看还原 |
| 分集 | 就绪/异常提示；全部/待处理/已公开筛选；5 行分页表格 | 每集 details；常驻上传/编辑表单和素材日志 | 以真实分集和缺集投影生成表格、筛选、分页；处理问题进对应集弹窗 |
| 批量上传 | 弹窗：选择文件→核对集数→上传与处理；映射表后才开始 | 选择文件即按数字直接上传，没独立映射核对 | 真实本地文件列表；视频/SRT 分开；可核对/修正数字映射，重复/越界/已公开或有效绑定冲突明确阻断；确认前零上传请求 |
| 上传运行/失败/取消 | 上传、处理各状态；不可虚报就绪 | 完成后整体重载，需手动找资产状态 | 按文件真实字节进度，轮询真实处理状态，失败重试/取消，离开保护；不复制成功计时器 |
| 分集编辑 | 640 px 弹窗，集数/标题；视频和字幕当前与候选分区；确认切换 | details + 原生文件选择后 prompt/confirm，多处行按钮 | 共享 dialog 内当前/候选独立区、语言控件、失败/取消/确认；保留 episode ID 和后端版本核验 |
| 基本资料/封面 | 双列表单，封面预览/更换入口，底部保存资料 | 常驻另一个上传表单与资产下拉 | 同位置显示绑定；更换打开上下文图片弹窗；实际就绪后明确保存 |
| 授权与试看 | 授权与 N 同一视觉卡，统一保存按钮/来源说明 | 两张常驻卡两套保存 | 按稿合并视觉及动作顺序；既有两接口顺序保存，不假称原子成功；失败明确已完成部分 |
| 发布草稿 | 左侧单选安排，右侧完整时间/集数清单及校验；确认弹窗 | 下拉大表单 + pre 输出；手动/恢复/下架全部堆叠 | 同稿双栏、完整排期、确认弹窗；动态真实总数和北京时间；保留 D03、缺集不追赶规则 |
| 发布 active/paused/finished/withdrawn | 状态摘要、后续排期、对应层级操作；编辑才展开安排 | 所有状态都常驻编辑/恢复/重新上架表单 | 分状态渲染；暂停/恢复/修改/提前批次/下架仅在适用位置；高风险动作弹窗确认 |
| 分类/Banner | 列表/卡片 + 新增编辑弹窗，横图在 Banner 内 | 列表后常驻编辑和上传表单 | 就近共享弹窗，真实数据回填与冲突保护 |
| 操作记录 | 表格 | pre 文本 | 真实 Content 操作与发布记录表格；不伪造操作人（投影无员工姓名） |
| 负责人默认 N | 原稿全局设置模块 | 片库常驻折叠表单 | 保留负责人专属入口，弹窗展示默认与影响清单；全局导航归 00，适配明记 |

必要真实字段适配：中/英文标题和简介、多个分类、排序、地区代码、授权说明和期限、字幕实际语言、未知总集数、文件失败/取消/冲突均保留；缺集根据真实已确认总数产生占位行，未登记集需先创建原 episode ID 后上传，不以集数覆盖其他记录。媒体 ready 不代表版权或语言已经核验。

拟修改文件：`resources/views/content/library.blade.php`、`public/content/admin.js`、`public/content/admin.css`、ContentLibrary 页面标题；必要只读聚合/预览适配限于 Content AdminController/独立路由。保留已验 MediaStore、ContentManager、PublicationService、PlaybackService 业务规则与并发锁，不改已采用迁移、公共文件或依赖。更新 Content 页面测试/浏览器复验、02 交接与本证据目录。
