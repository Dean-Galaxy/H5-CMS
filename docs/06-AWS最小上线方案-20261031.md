# AWS 最小上线方案候选

2026-10-31；只读核查应用基线 **`2c2a2956c69cf687f237d2603d91a0f1201b4492`**，契约1.0.5。仅方案，未采购、未登录AWS、未创建资源或部署；已关闭的R1/C2/周四环境不动。当前应用不能直接开放投流和地区受限播放，先由00接收下面缺口，再冻结部署候选。

建议先做**单区域、单机、限制访问的HTTPS联调站**：Lightsail Linux实例运行Nginx、PHP-FPM 8.4、PostgreSQL17、FFmpeg/ffprobe、一个队列worker和唯一scheduler；PG只监听loopback，媒体保留在站点public以外。数据库自管是本方案明确的运维成本，单机不是高可用；不要求一开始开RDS、Redis、负载均衡或CDN。候选区域以 `us-east-1` 演算，服务可用不等于用户或合规范围已获准。[AWS区域](https://docs.aws.amazon.com/lightsail/latest/userguide/understanding-regions-and-availability-zones-in-amazon-lightsail.html)
