## 拟采用的最小信任链

候选A（本轮优先）：浏览器 → 直接HTTPS Nginx → Unix socket PHP-FPM → 应用。单服务器，数据库仅回环，媒体在public之外。没有边缘代理；Nginx实际TCP对端地址是唯一IP输入。所有客户端 Forwarded、X-Forwarded-*、X-Real-IP、CF-IPCountry、CF-Connecting-IP及自定义国家头均不作为地区依据。Nginx显式清空这些输入，FPM使用服务器生成REMOTE_ADDR及HTTPS=on，拒绝非规范Host；PHP-FPM不监听公网。Laravel trusted proxies 为空，不允许*。

地区提供方候选：00接入本地只读IP国家数据库，按实际对端IP查找。数据库来自已选择服务商的正式文件和版本/摘要登记，定期更新；本轮不下载未获授权数据库、不猜IP、不硬编码US。仅可解析的有效公网IPv4/IPv6返回country_code/source=trusted；私网、回环、保留地址、无结果、库缺失/过期/损坏均返回ZZ/unresolved（或明确依赖失败），拒绝购买及受限内容。购买和播放使用同一RegionResolver。IP国家判断不是居住地或法律合规证明。

候选B（以后决定使用边缘时）：浏览器 → Cloudflare边缘 → 受限源站Nginx → Unix socket PHP-FPM。必须同时具备最新官方IP范围、防火墙仅允许该边缘、该站专属Authenticated Origin Pulls证书或等效站点绑定认证（共享边缘IP本身不足以隔离其他租户）。配置未经部署证据验证，不允许返回trusted。只在原始TCP对端和客户端证书均合格时采用由边缘重建的国家/IP头；源站不得可被公网直连，不能信任经过real_ip改写后的地址来判断边缘身份。头需去重并严格校验，XX/T1/空值/多值/非法国家码均拒绝。Laravel只信任实际反代精确来源，源站入口强制HTTPS与规范Host。未决定使用B前不添加CF头信任、通配代理或假IP列表。

A不需要边缘/对象存储媒体适配，是当前代码最少依赖的测试站方案；供应商、域名、IP、地区库账号及预算仍待用户选择。代理拓扑改变是重新验收点，不能仅在控制台开启代理后沿用A报告。
