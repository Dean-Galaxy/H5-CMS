F02：业务已含分类和 Banner，候选只有 catalog/drama。新增 HomePage、CategoryList、Category、HomeBanner、DramaCard、homepage/categories 读取接口；catalog 追加可选 categoryId，HTTP 追加 category_id，详情补 locale 参数。约定排序、语言回退、下架/授权过滤、游标和站内目标；不实现 CMS 或媒体导入。

详见 `docs/contracts/shared-v1.md`、OpenAPI、examples 及 PHP 类型。
