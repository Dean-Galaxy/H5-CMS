## 入口与排布

| 从上到下，仅当前tab显示 | 内容与交互 |
|---|---|
| 查询与快照 | “仅合成测试样本”徽标；UTC起始（含）/截止（不含）两输入，完整ISO8601带Z，不按浏览器本地时间解释。默认Reader同次快照最近7天，最长连续7天、截止≤as_of；显式“查询”，不随输入轮询。结果显示已应用范围、只读“数据截至…UTC”（as_of）、报表/政策/notice/schema版本及覆盖；分组不混算。 |
| 主链 | 各版本组一张三行表：**E 页面入口 → D 固定目标剧 → P 实际播放开始**；列“步骤 / 已观测会话数 / 相对上步已观测比例”。E比例—，D/E、P/D仅同组有序前阶，0分母—。短注：“同会话每阶一次，首个有效详情固定目标剧；换剧不改目标，请求/预载不算播放。尾部观察可到as_of/已知边界。” |
| 观察与分支 | 小汇总表显示Reader返回的“观察中”“已知截断，原因未证”“窗口结束未观察到”“覆盖未知”；不把观察中当在线/仍获准，不猜退出或流失。另列“直接进入”“无E前序”“有播放但缺D”及其他缺前序结果。直接进入有E/D/P可入主链，类型标记不与主链相加；缺前序不凑主链。各项不预设互斥、不自行加总。 |
| 独立结果 | 标题“已记录可信结果会话数”；成功/失败各自去重，附独立用途/notice版本。注明“按结果收件时间入上述窗口，与入口队列不同，不相除”；无记录“无证据”，不相加推断人数。底部“注册完整链：未接入”“付款：未接入／不适用”，不放0%或金额卡。 |

示意：`既有tabs → UTC查询/快照 → E·D·P → 观察/缺前序 → 独立结果`。复用workspace、tabs/panel及h5-card、h5-form-grid/h5-input、h5-table-wrap/h5-table、h5-badge/h5-note/h5-alert/h5-error；窄屏字段改单列、表格自身滚动。不加壳、图表库、公共CSS或更多子tab。固定短注：“仅合成会话观测，不代表真实人数或最终转化；查看不会开启采集。”

## 五个关键状态文案

| 状态 | 文案及规则 |
|---|---|
| 读取中 | “正在读取只读快照…”；防重复查询、结果区aria-busy/播报。旧结果不冒充新范围，保留输入，不自动重试。 |
| 有效空样本 | “当前范围无可纳入主链的合成入口会话，不代表全站没有行为。”仅读取成功可显示主链0、比例—；独立结果按自身返回，无记录“无证据”。 |
| 超限/有限覆盖 | “入口超过10,000会话处理上限；本次仅处理{后端确认数量/范围}，不代表全量。请缩短UTC范围。”显示limited及实际覆盖，主链比例统一—；其他覆盖未知就地标明，不填0掩盖。 |
| 不可读 | 无权：“你无权查看C会话报表。”未就绪：“C会话报表尚未就绪，当前无法读取。”按真实原因区分，不渲染零值表、不引导开启采集。 |
| 读取失败 | “报表读取失败，未将未知结果显示为0。请重试查询。”保留筛选，仅用户重查。日期校验就地提示：“请输入有效UTC起止时间，范围最多7天且截止不得晚于本次数据截至时间。” |
