### 未勾选与明确拒绝不同

- 新目的unknown且未操作：不预勾；显示“尚未选择”，提交时not_requested，**不是**自动写deny或撤回旧选择。
- 已有同scope、同当前可信账号的allow：按回读显示，未改动不重发/续期；已有deny保持显示拒绝。不能用初始false或缺省字段覆盖旧值。
- 用户明确取消已勾项或使用“拒绝本项”：形成明确deny草稿，提交前显示“本项将保存：拒绝”。两项分别处理；不以静默不勾代替“拒绝所有分析”。
- 读取未完成/能力未知：不把两个空框伪装成服务器已拒绝。可选区呈未确认/不可用，必要账号仍可按既有流程创建。若账户已创建，只继续处理偏好，不重新显示“创建账号”作为重试入口。

## 3. 管理页：真实choice、实际运行、旧广告分列

每项复用原设置卡/字段/按钮，显示“已保存选择”与“实际运行”两行；允许和拒绝编辑是本项草稿，不能立即改已保存标签。每项独立“保存本项”“拒绝本项/撤回允许”；不必新造总保存事务。本站会话的关闭仍走既有独立动作，不用v3选择接口假改C。

| 回读状态 | 中文显示 | English |
|---|---|---|
| choice=unknown，能力choice_only | 已保存选择：尚未选择。实际运行：未运行，本轮仅可保存偏好。 | Saved choice: no choice yet. Processing: off; this test only saves preferences. |
| choice=allow，保存确认且effective=false | 已保存选择：允许。实际运行：未运行（仅保存偏好）。 | Saved choice: allow. Processing: off — preference saved only. |
| choice=deny，真实确认 | 已保存选择：拒绝。实际运行：未运行。 | Saved choice: deny. Processing: off. |
| unavailable或说明未真实交付 | 本项暂不可用，未确认可保存；不影响必要建号或继续使用。 | This preference is unavailable; saving is not confirmed. Account creation and necessary services remain available. |
| account_link reason未就绪 | 账户分析关联尚未开放；选择不会建立关联。 | Analytics account association is not available. Saving a choice does not create it. |
| advertising reason关闭 | 广告外发未开放；保存允许不会发送广告事件。 | Advertising delivery is disabled. Saving allow does not send advertising events. |
| site_session已拒绝/旧有效拒绝 | 本站会话分析已关闭，沿用原拒绝；注册或登录不会自动重新开启。 | Site session analytics is off, honoring the earlier refusal. Registering or logging in does not turn it back on. |
| 旧广告独立行 | 此前独立广告选择：[允许／拒绝／尚未确认]。它不是本次R1选择，也不会被本次“允许”自动升级。 | Separate earlier advertising choice: [allow / deny / unconfirmed]. It is not the R1 choice and is not upgraded by saving allow here. |

仅在最新真实回读支持时显示“服务器已确认拒绝/停止约束”；新广告deny应落实冻结的旧管线退出约束，但不能只凭本R1偏好成功就泛称历史广告/所有设备全部关闭。原site deny不顺带撤回旧广告。新旧广告按不同scope分别显示，不出现两个相同“广告已同意”让用户猜哪一个生效。

明确写“选择范围：当前浏览器；允许选择仅对当前登录账号可见。不是跨设备开关。” / “Scope: this browser. Allow choices are visible only for the current signed-in account. This is not a cross-device switch.” 退出/换号后不能继承上一账号allow或草稿；浏览器必要deny继续保持。旧允许回执晚到时以当前真实state为准，不把操作曾成功当成现在仍允许。

R1没有完整总用途确认时，不展示虚假的“关闭全部成功”。若保留原稿整体关闭入口，必须分别取得C、新两用途与涉及旧广告的真实确认并逐项展示；本批不为凑原稿额外发明一键总流程。分项拒绝、C独立关闭和继续使用始终可达。

## 4. 部分成功、未知与显式重试

账号结果、账户偏好结果、广告偏好结果三行独立。用户在账号成功后只需选“继续使用”或对失败项目操作，不因可选保存失败重填口令/接受条款/重新注册。主提示不要只报“保存失败”，要指明哪一项。

| 场景 | 中文copy／动作 | English copy / action | 定向规则 |
|---|---|---|---|
| 两项均未请求变更 | 账号已创建。未请求变更可选偏好；原有选择保持。／继续使用 | Account created. No optional preference changes were requested; existing choices remain. / Continue | not_requested是本次无请求，不是服务器持久选择，也不代表所有分析关闭 |
| 一项成功、一项503/存储或网络未知 | 账号已创建。账户关联选择已保存为允许，当前未运行；广告选择尚未确认。／重试广告偏好、继续使用 | Account created. Account-linking choice saved as allow; processing remains off. Advertising choice is unconfirmed. / Retry advertising preference; Continue | 可互换两目的。只重试未确认项，不重发已成功项、密码/注册；草稿仅本页内存，不存浏览器持久队列 |
| 409版本/notice冲突 | 本项设置已变更，请核对最新选择；你的草稿已保留。／采用最新选择、明确重新保存本项 | This preference changed. Review the latest choice; your draft is kept. / Use latest choice; Save this item again | 先读真实state/notice/revision，展示草稿与最新值差异；不自动重放旧allow/deny。新notice需先实际可读，不用盲重试越过 |
| 响应未知或超时 | 未确认本项是否保存，不表示已失败或已允许。请重试核对；账号无需重复创建。 | We could not confirm whether this preference was saved. This is not confirmation of failure or permission. Retry to check; do not create the account again. | 按冻结幂等规则核对同一意向，不能每次点击重造逻辑操作而重复证据/续期；技术机制不进主文案 |
| 选择读取失败 | 可选偏好暂时无法读取。当前草稿保留，不会自动覆盖已有选择；可继续使用或重试。 | Optional preferences could not be loaded. Your draft is kept and will not overwrite existing choices automatically. Continue or retry. | 读取失败不是默认deny/allow；C实际状态另读另显，不用v3失败伪造C已停/已开启 |

| notice没交付／提供方未就绪 | 可选偏好尚未就绪，目前无法确认保存；你可先创建账号或继续使用。 | Optional preferences are not ready, so saving cannot be confirmed. Create your account or continue using the site. | 无效说明/依赖不能勾成“已允许”。需区分v3偏好能力与第7节注册结果测量能力，见下文 |
| 429限流 | 本项操作较频繁，请按提示稍后核对或重试；未确认的结果仍未确认。 | Too many requests for this preference. Wait as indicated, then check or retry. Unconfirmed results remain unconfirmed. | 尊重服务端等待时间，不自动反复发送、不借C关闭预算重试；如果此前另有未知操作，不说其已被撤销 |
| 422字段错误 | 本项选择未能保存，请检查提示后重试。 | This preference could not be saved. Check the highlighted issue and retry. | 只提示本项，保留另一项成功结果及可保留草稿；不展示输入秘密/服务端堆栈 |
| 账号结果本身未知 | 注册结果尚未确认；请先尝试登录或找回密码，不要重复提交注册。 | Registration could not be confirmed. Try signing in or resetting your password before submitting again. | 不能提前称账号已创建，也不继续依赖未确认身份写allow；沿正常身份错误防泄露规则，不公开枚举邮箱 |

## 5. 第7节PHP端口：哪些信息该给用户，哪些留给工程

`RegistrationMeasurement::availability()`只说明真实适配依赖，不等于政策允许、C已开、本人同意或两项偏好可写。capture/record是服务端注册结果测量，不是可选偏好保存接口。主页面不展示capture对象、Accepted/Skipped/Retry等内部过程，也不以它们判账号是否成功。

- 注册结果测量依赖缺失/Skipped/Retry/抛错，不能倒退必要账号/条款结果或重发注册。若只是结果统计没准备好，不把可用的v3偏好区全部错误标成不可用；反过来也不把PHP适配Available当v3已经可写。
- 说明未实际呈现时，不得凭隐藏notice/version字段假装已告知；R1页面的可读说明与服务端交付依据按契约验证。无有效原C不新建、不补历史；注册成功按必要事务提交后的可信结果处理，邮件/回程故障不改记注册失败。
- 页面只反馈对用户有意义的账号与偏好结果。没有注册统计事件不是用户“注册失败”，也不承诺所有注册都进入完整漏斗。邮件仅本机预览，不写真实送达或邮箱已验证。

### 内部错误码的明确设计建议

**主提示移除内部枚举/类名/原始HTTP错误文本；用上表可理解的用途与行动说明。排错保留在可展开“技术详情（可选） / Technical details (optional)”中。** 这沿用既定短错误/细节分层，不要求本轮新做日志系统。

| 信息 | 主界面 | 可展开详情 |
|---|---|---|
| ASSOCIATION_NOT_READY / EXTERNAL_DISABLED | 账户关联尚未运行／广告外发关闭；偏好可保存与否另据capability显示 | 安全原因码可显示，不能把原因码当唯一解释 |
| DEPENDENCY_NOT_READY / POLICY_UNRESOLVED / 503 | 偏好暂不可用或结果未确认；提供继续使用/明确重试 | 真实HTTP状态、安全原因码和白名单脱敏关联号；不暴露供应商凭据/内部路径 |
| 409 / 401 / 403 / 419 / 429 | 最新设置冲突／登录状态变化／权限限制／页面过期／稍后重试 | 保留对应安全代码和等待提示，便于工程对照；419不得自动重发注册/密码 |
| 版本/操作回执 | 用“已保存/未变更/未确认/请核对最新说明” | 必要时显示公开测试版本及脱敏回执，禁止放表单内容、账号邮箱、口令、proof、测量/账户标识映射或原始堆栈 |

未知代码用“暂无法确认本项结果”并保留安全详情，不能直出后端英文字符串。详情不是完成拒绝/重试的必经步骤；不能藏唯一可操作错误说明。需要工程诊断的安全字段由01/04/05白名单提供，08不授权额外采集/暴露个人资料。
