## 问题与修正

未知注册响应后，me确认同邮箱当前账号已登录，只能证明当前身份可用，不能证明本次POST新建了该账号。原complete方法会把该路径一律覆盖成“账号已创建”。

现在只有明确注册POST成功的调用传入本页creationConfirmed=true；me恢复调用默认false。英文恢复提示为“Your current account is signed in. Continue using the site or review your preferences. This does not confirm that this registration request created the account.”；中文为“已确认当前账号已登录。可继续使用或核对偏好；本次注册是否新建账号仍未确认。”

用途保存未确认提示也去掉预设“账号已创建”的前缀，避免未知恢复后在单项反馈里再次误报。明确POST成功仍显示原账号已创建提示。两条路径继续使用相同可信账号核验和dirty选择提交，不重发注册/密码或已保存项；匿名/换号仍不授权用途提交，没有新增自动重试。
