实际 PHP 8.4.26 / Laravel 13.35.0 / Filament 5.9.0 / Fortify 1.41.0 / Cashier 16.8.0 / PostgreSQL 17.11，完整结果见 [环境与依赖审计](../01-环境与依赖审计.md)。Cashier 自动发现关闭，未复用旧认证/支付逻辑。

三项初始迁移由 start 执行，独立测试库从空库安装通过，已有开发库再启动显示无待迁移。以后不改已采用迁移。后台首次绑定验证器后重新登录；动态码/恢复码通过才建立 MFA 会话证明。权限版本和停用状态逐请求复核，改密码/角色/启停撤销旧会话。审计不存明文密码、邮箱、完整链接或支付数据。
