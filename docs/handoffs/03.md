### 页面与业务行为

- “订单查询 / 会员价格 / 客服记录”分栏，一次显示一个内容区；保持标签和所选记录的 URL 上下文。负责人可查最近 50 笔订单和全部客服记录；客服只显示本人记录，按用户提供的完整订单号查询，所有动作继续检查服务器权限与 MFA。
- 负责人使用美元字符串输入，例如 `12.34` / `3.21` 精确存为 `1234` / `321`，再读回 `$12.34 USD` / `$3.21 USD`。空白、错误类型、指数、超精度、超界、零/负价格和旧版本冲突明确拒绝；首周不高于常规，仍须勾选测试价格。未配置时金额留空，没有自动填入样例价。
- 订单、已付金额、实际退款、原订单约定周价及当前订阅下次金额使用公共 UsdAmount 展示；内部 DTO、账本、SDK、PaymentSettled 始终是整数最小单位。原 Offer、订阅约定、付款、权益与 outbox 不因调价改写，旧报价和原价恢复规则保持。
- 未保存价格、核实选项和备注，在标签/页面/所选记录切换时可“保存并继续 / 放弃修改 / 继续编辑”；校验失败或结果未知留在编辑处。刷新/关闭由浏览器原生确认保护。共享键盘焦点问题已交 00 修复并在真实页面复验。
- 客服代取消前仍需核实身份与当前请求；未知结果不报成功，已消费的核实勾选重读清除，备注等输入保留。无退款、加时、伪造付款或擅自恢复入口。旧订单约定价与账号当前续费价分开标注。
- 本轮没有既有导出/汇总入口可转换，不新增 CSV 或报表，不改购买、退款和归因业务规则。
