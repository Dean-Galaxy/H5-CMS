## 观察器范围与修正

源码为`scripts/ops/observers/r1_faults_v2.cjs`及`r1_faults_core.cjs`，一次仅一个原定case：

| case | 实际后端与故障性质 |
|---|---|
| partial-503 | 真实账号/A选择成功，B响应显式客户端503；只显式重试B、A不重存 |
| lost-registration-json | 注册真实提交与会话Cookie保留后仅JSON回程损坏；me只证明当前账号，不重注册 |
| lost-purpose-json | 真实选择已保存后JSON损坏；仅显式重试原operation，核账号/收据保持 |
| network-before-purpose | Playwright明确中止一个目的请求、该请求未到服务器；恢复后显式重试 |
| identity-unavailable | 目的保存前me显式503，零目的PATCH；恢复后分别明确重试 |
| status-401 / status-403 | 明确客户端返回，等真实响应事件及account_unknown/草稿清空/重试隐藏DOM全部完成，再核广告未发/无自动重放 |
| status-419 / status-422 / status-429 | 明确客户端状态，分别未确认/验证失败/Retry-After倒计时；不能说真实服务器异常已发生 |
| actual-cas | 原匿名deny/rev1，真实竞争allow/新operation→rev2，再放原allow/rev1得到真实409。显式重试allow/rev2应为unchanged/未运行，核新operation、真实版本及proof完整行摘要不续期 |

修正原CAS同值deny不增版本、硬等saved及401/403仅等created文案的夹具错误；原绑定`r1_browser.cjs`保持字节，原`browser-faults`不被冒称通过。响应/草稿未完成、429、坏JSON、异步路由错误等均在单个场景私密首败回执记录，不自动整组重跑。
