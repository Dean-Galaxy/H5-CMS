## 00需收敛的共同约定

- 处理决策：是否允许、目的/依据/政策版本、用户实际选择、地区/受众资格、拒绝/撤回/GPC各自状态、有效期；浏览器只消费可信服务器结果，不能提交自造地区/许可。
- 会话识别：短期随机伪名和访问会话的范围、过期、旋转、退出换号、登录前后可选关联；不使用IP/指纹猜人，不以鉴权cookie暗中替代分析标识。
- 事件：沿用已接收page/play/watch/paywall/register/checkout/payment等语义和防重；具体剧/集仅内部引用。服务器权威结果与浏览器点击分开，失败枚举不带邮箱/堆栈/素材URL。
- 漏斗：同一合法会话/主体有序推进；观察窗和还在观察中的样本分开。断网/拦截/清缓存/跨设备缺失必须可解释，不能声称覆盖全部真实人数或准确离开原因。
- 数据期限：标识/会话、逐条行为、账户关联、拒绝及权利证据、服务器日志、广告标识和发送记录、备份分别给目的/期限/清理责任。不能把cookie失效冒称数据库和备份已删除。
- 注册：必要账户条款、隐私告知、可选增强关联和广告分别处理，失败不重复注册、不把失败保存显示为成功；确认前/之后的数据边界明确，不追认禁止采集的数据。
- 广告：D05原规则保持；本站C数据不能自动转Meta/TikTok。普通推广参数的站内渠道用途另核，不能因此提前缓存广告ID/完整URL。涉及视频信息的第三方载荷必须专项核查。实际广告仍关闭。
- 向后兼容：旧analytics granted/denied/unknown、既有订单快照、可靠付款待发、退出与真正撤回分别处理，不更改既有付款/权益事实；旧拒绝不能被C策略覆盖。
