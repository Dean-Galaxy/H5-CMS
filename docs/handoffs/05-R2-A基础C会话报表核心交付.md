- `groups`按合成主体策略/notice及事件schema分组，E/D/P与已观测n/d（0分母—）；观察中、已知截断、窗口结束未观察P、覆盖未知独立元数据。29天前创建/关联或样本不合等缺证显式标注；只计算保留的观察，不猜实际动作顺序、原因或历史政策。覆盖未知不是完整观测承诺。
