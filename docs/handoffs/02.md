## 产品经理怎样使用

1. 在本工作区运行 `python3 scripts/dev.py start`，然后打开上述后台入口。已建立的本地验收账号凭据仅在 `.runtime/content/preview-account.json`（不入 Git），浏览器当前会话可直接使用。需要自己的负责人账号时按 `docs/01-开发接入说明.md` 使用 `python3 scripts/dev.py owner` 并完成真实二次验证。
2. 在“片库”选择编辑，或“新增剧目”后保存草稿。填写实际总集数、地区、授权起止和登记说明；登记不表示真实版权审核已通过。
3. 在“上传和分集”选择视频/字幕/封面/Banner。数字文件名会按序登记分集，字幕语言需人工选择。上传完成仍是待处理；点“刷新状态”等待就绪。失败可重试；未完成上传可取消。
4. 选定封面、分类并保存。先用每集“草稿预览”核对画面、音轨与字幕。默认已完结模式只允许全集准备好后一次发布；要分批，保存为“更新中”。
5. 手动发布填写连续发布至第几集，先预览，再确认立即发布。排期则保存计划、预览、确认启用；默认北京时间次日 00:00，保存后日期固定。暂停保留已公开内容，恢复需重新确认未来时间；下架后必须明确恢复或重设。
6. “负责人：全局默认免费集数”先展示仅新剧或同步未覆盖剧的影响清单，再确认。内容运营不能通过页面或 API 更改该设置；手动保存相同 N 也算单剧覆盖。
7. 状态查询 `python3 scripts/dev.py status`。停止本工作区服务 `python3 scripts/dev.py stop`，保留数据库及素材。不能卸载 KESU 后继续使用媒体预览；需要重新启动前先接回该卷。

正常处理每分钟由定时任务取一份文件。批量验收可在本工作区执行 `/opt/homebrew/opt/php@8.4/bin/php h5-platform/artisan content:process-media --limit=200`，只处理、不发布。不要并发修改同一剧目的基本信息；遇到版本变化先刷新并检查。

## 播放与依赖边界

Identity、权限、MFA、审计、会话、数据库及本地 FFmpeg 均真实接通。MembershipReader 普通运行仍是 03 未接入的显式 503；测试中的会员有效/退款失效对象是严格限 testing 的测试替身，没有真实付款、退款或会员验收。

公开契约只返回短期 HLS 许可，源文件及持久文件路径不返回网站模块。清单、字幕、分片、MP4 Range 每个新请求都核验签名、当前服务器会话、地区、发布与期限；需要会员的请求还读取 03。许可最长 120 秒，可提前被授权期或会员到期缩短。

只有实际 GET 到有效视频数据才标记开始。单集连续窗口从首次读取固定为 `2 × 视频时长 + 300 秒`，续签不延长。仅免费 N 变化保留这个已开始会话；刷新、切集、登录/退出须传空 `play_session_id` 重判。退款/会员失效、下架、地区或版权期限变化分别校验，不能依赖免费 N 例外绕过。已发送或已缓冲字节不能收回，正在响应的 Range 不会中途追回。04 仍需实现到期前续签与播放位置衔接，真机 HLS/播放器组合尚未验收。

字幕保留原文与原时间，乱序条目稳定排序。HLS 响应按实际 remux 后视频时钟加入 [RFC 8216 第 3.5 节](https://www.rfc-editor.org/rfc/rfc8216#section-3.5) 的时间映射；员工 MP4 预览使用原 VTT 时间。抽样看到英文字幕不等于全剧翻译质量和音画同步已人工验收。
