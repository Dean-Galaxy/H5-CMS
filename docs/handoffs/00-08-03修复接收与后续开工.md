## 怎样让后续任务开工

1. 04、05、06 分别使用自己的对话和独立 Worktree。复制对应的[04 完整提示词](../多任务开发规划/提示词/04-观众网站与观看进度.md)、[05 完整提示词](../多任务开发规划/提示词/05-投流链接与像素.md)、[06 完整提示词](../多任务开发规划/提示词/06-系统验收与部署.md)，不要混发给一个任务。
2. 提示词已要求核对 `h5-billing-v1`、契约 1.0.2、本文和台账。已有工作区正常合并新起点，保留改动；不重置，不复制其他工作区的账号、数据库、素材或 `.env`。
3. Identity、Content、Billing 已默认接入。04 创建 `App\Modules\Audience\AudienceServiceProvider` 后在自己的 local 环境启用 `H5_LOCAL_MODULES=audience`；05 同理使用 `App\Modules\Acquisition\AcquisitionServiceProvider` 和 `H5_LOCAL_MODULES=acquisition`。类尚不存在时拒绝启动是预期行为。
4. 新工作区数据库和素材为空，需要各任务自己准备最小测试资料和明确的测试价格。美国本机场景仍须显式启用自己的 `H5_LOCAL_US_TEST_REGION=true`；未知地区不能自动当美国。默认缺 Stripe 凭据时无法完成真实 Checkout，这是如实报告外部缺项。
5. 每个任务交固定提交、交接单和证据；00 负责串行合并。发现问题直接回原模块修复，用户不用手工搬代码。
