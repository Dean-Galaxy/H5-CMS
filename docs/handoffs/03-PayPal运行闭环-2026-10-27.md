## 必须保留的兼容性限制

以下是当前程序的明确边界，不是“官方已支持”的结论，也不是可忽略的验收项：

1. 商户身份从 `GET /v1/reporting/balances` 的 `account_id` 核对，余额不记录。此App是否具备官方要求的读取权限尚未验证。预检失败返回固定诊断 `PAYPAL_MERCHANT_CHECK_UNAVAILABLE_OR_MISMATCH` 并阻止购买；不能要求用户盲目申请额外权限或删掉核验。若失败，03需把官方替代身份核验方案交00确认后继续。
2. 自动周期入账目前要求完整连续交易、无欠款/失败痕迹、执行次数与交易数一致、周起点与next_billing_time一致、每笔独立Sale匹配。失败后重试/合并欠款/缺历史/取消后缺next_billing_time/迟到首笔等不充分证据保持待核，**本交付没有完成这些官方兼容性验证，也没有人工直接加权益绕过**。后续只能凭真实官方样本及可复核规则补适配。新订阅必须始终保持阻止重复创建。
3. 交易读取每30天分窗，要求返回的total_items/total_pages明确证明单页完整；有next或多页会停在待核。回溯超过两年也待核，尚无长历史分页优化。订阅执行次数或last_payment领先于交易列表时不释放占位。
4. 订阅Sale/Refund读取使用官方仍列出的 **deprecated Payments v1** 只读端点。实际Sandbox App兼容性未验证；不能用Orders Capture对象替换来伪造同等结果。
5. PayPal resumeQuote/resume继续拒绝，原价/原日期/不立即扣款无官方证据前不开放activate。Stripe原F01不变。退款/冲正没有新建普通退款审批流，法定异常入口仍归00。
6. 已知退款更正可自动重读；丢失的整笔全退可由Sale全退事实撤对应权益，但缺失部分退款ID时金额明细仍可能不全，不捏造退款流水。

## API版本及事件映射

固定主机 `https://api-m.sandbox.paypal.com`，TLS校验、禁重定向/代理、超时、响应大小限制；没有Live主机切换。REST路径版本为v1，无Stripe式日期版本请求头。APP_ENV=testing只允许注入Mock，拒绝意外真实网络。

| 官方端点/通知 | 处理 |
|---|---|
| `/v1/oauth2/token` | Client Credentials，内存短期token，不输出 |
| `/v1/reporting/balances` | 仅取实际account_id，与本地固定商户匹配 |
| `/v1/catalogs/products`、`/v1/billing/plans` | 明确TEST产品；计划价快照、原幂等键创建和重读 |
| `/v1/billing/subscriptions`、`/{id}`、`/{id}/transactions` | 创建/读当前事实；完整交易与周期交叉验证 |
| `/{id}/suspend`、`/{id}/cancel` | 停止未来续费及终态清理；重读确认 |
| `/v1/payments/sale/{id}`、`/v1/payments/refund/{id}` | 只读实际付款/退款，deprecated接口风险见上 |
| `/v1/notifications/verify-webhook-signature` | 正式App Webhook ID及完整签名头，不接受模拟器WEBHOOK_ID |
| `PAYMENT.SALE.COMPLETED` | 按Sale找本人原订阅，重新查询事实，不信通知金额 |
| `PAYMENT.SALE.REFUNDED` | 读取实际Refund与关联Sale，重算该付款退款结果 |
| `PAYMENT.SALE.REVERSED` | 记录待核并停止意图，不造退款 |
| `BILLING.SUBSCRIPTION.CREATED/ACTIVATED/UPDATED/SUSPENDED/CANCELLED/EXPIRED/PAYMENT.FAILED` | 只作为重读当前状态的提示；旧ACTIVATED不能覆盖后来取消 |
| 未知事件 | 标明忽略，无付款/权益副作用 |

官方依据：[订阅交易](https://developer.paypal.com/api/subscriptions/v1/subscriptions-transactions)、[失败重试](https://developer.paypal.com/subscriptions/payment-failure-retry)、[Sale查询](https://developer.paypal.com/api/deprecated/payments/v1/sale-get)、[Refund查询](https://developer.paypal.com/api/deprecated/payments/v1/refund-get)、[Balances及account_id](https://developer.paypal.com/api/transaction-search/v1/balances-get)。这些是接口依据，不是本App执行回执。
