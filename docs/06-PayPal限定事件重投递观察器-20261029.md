## 能证明什么

工具只观察经过现有桥、正文中 `id` 精确匹配一个私密固定事件的传输。对同一事件可以记录两次不同的transmission摘要和实际上游HTTP响应；这可证明匹配请求确实通过桥到达应用处理器，记录本身不验证来源或签名。猜中事件ID的伪造请求也可能被记录，因此每条强制 `signature_verified=false`，包括上游200的情况。

验收重复官方通知仍须00分别证明：官方操作/通知来源、应用当前验签处理路径及该事件processed、第二次实际入站、原订单/付款/权益及13类账务完整行和时间戳保持。resend返回202、官方事件GET成功、相同event摘要的两行传输记录，任一项单独均不足以宣布账务幂等通过。没有记录也不能反推没有投递：过期、窗口变化、无上游响应、日志满或写锁竞争时会跳过观察，应用的处理响应保持原样。

## 默认、数据和边界

- 现有 `scripts/ops/tests/paypal_external_observer.py --synthetic-id <本窗口合成marker>` 默认仍只生成合成透传回执；不会读取真实事件策略。另加显式 `--observe-event` 才尝试启用真实事件观察，没有真实event ID命令行参数。
- 固定策略仅位于 `.runtime/paypal-sandbox/replay-observation.json`，输入文件0600、实际用户owner、普通文件且单硬链接；拒绝symlink，`.runtime`与`paypal-sandbox`目录须0700且属于当前用户。无效策略使显式观察模式启动失败，错误信息不回显输入。
- 策略指定唯一事件ID、工作区根、当前marker摘要、origin摘要、tunnel PID与启动时间及过期Unix秒；最长未来1小时，建议30分钟。每次选择及记录都复核完整现有window guard，包括固定端口、完整tunnel命令、进程启动时间和PID；记录里的bridge PID还必须等于本观察进程。不读取env或支付凭据，不调用官方API。
- 原始正文仅在内存筛选；保留桥既有的256KiB、4并发、每分钟60请求及超时边界。UTF-8/JSON错误、重复JSON key、深层异常、不匹配ID、非法transmission格式只跳过观察。桥对路径、Cookie/Auth、头和类型的原有拒绝逻辑保持不变。
- 新日志只含 `event_id_sha256`、`transmission_id_sha256`、`body_sha256`、`body_bytes`、`upstream_status`、UTC `observed_at`、顺序 `count` 及固定false的 `signature_verified`。不保存正文、真实ID、五头原值、签名、token、IP或应用响应正文。上游302原值可记为302，但桥仍对调用方返回502；计数不是验签成功次数。
- 输出为同目录 `replay-observations-<窗口绑定摘要>.jsonl`，0600；最多64条、64KiB，不自动轮转增长。非阻塞文件锁避免阻碍通知；已有日志权限不符、symlink/硬链接、损坏或超限则不写、不替换。固定窗口和策略下重启会续写计数；切换事件不得把旧日志混为新样本，应由00另存证据、明确安排新观察批次。
- 原合成marker的 `external-upstream.json` 仍仅作合成五头/字节回执；真实事件观察不增加五头或签名摘要到新日志。真实事件ID、策略、窗口地址和所有实际日志均不入Git。

import json, os, stat, sys, time
root = Path.cwd().resolve()

换桥只停止已核对的本次bridge，保留相同隧道/URL/marker；旧完整窗口在停桥前须通过 `active_window_url`。**不要调用 `paypal_stop_callback_window.py --stop` 来单独换桥，它会关闭桥和隧道两个进程。** 进程号不能照抄报告，始终从当前0600记录读取并核对命令及启动时间。

以下公开示例给出完整操作和原子记录更新方式，供00在选定窗口审查执行；默认示例显式启用本观察模式。回滚到默认合成观察模式时，仅将 `observe = False` 后按同一流程换桥，保留新日志及原私密策略供审计。两种操作均不更改业务/env/数据库或购买开关。

```python
from pathlib import Path
import json, os, signal, subprocess, sys, time
root = Path.cwd().resolve()
sys.path.insert(0, str(root / 'scripts/ops'))
from paypal_replay_observation import private_read
from paypal_complete_webhook_url import active_window_url, process_command
from paypal_stop_callback_window import matching
from paypal_apply_credentials import atomic_private
observe = True  # 回滚默认合成模式时改False；没有真实事件ID参数。
folder = root / '.runtime/paypal-sandbox'
path = folder / 'external-processes.json'
original = private_read(path, 16384)
record = json.loads(original)
active_window_url(root)  # 完整当前窗口检查；失败即停止操作。
marker = json.loads(private_read(folder / 'external-probe-marker.json', 4096))['transmission_id']
token = 'scripts/ops/tests/paypal_external_observer.py --synthetic-id ' + marker
pid = record['bridge_pid']; started = record['process_started_at']['bridge_pid']
assert matching(pid, token, started)
backup = folder / ('process-record-before-observer-' + str(time.time_ns()) + '.json')
backup_fd = os.open(backup, os.O_WRONLY | os.O_CREAT | os.O_EXCL | os.O_NOFOLLOW, 0o600)
with os.fdopen(backup_fd, 'wb') as stream:
    stream.write(original); stream.flush(); os.fsync(stream.fileno())
os.kill(pid, signal.SIGTERM)
for _ in range(50):
    if not matching(pid, token, started): break
    time.sleep(0.1)
assert not matching(pid, token, started)
assert private_read(path, 16384) == original
command = ['/usr/bin/python3', 'scripts/ops/tests/paypal_external_observer.py', '--synthetic-id', marker]
if observe: command.append('--observe-event')
log = folder / ('bridge-replacement-' + str(time.time_ns()) + '.log')
fd = os.open(log, os.O_WRONLY | os.O_CREAT | os.O_EXCL | os.O_NOFOLLOW, 0o600)
with os.fdopen(fd, 'wb') as stream:
    new = subprocess.Popen(command, cwd=root, stdin=subprocess.DEVNULL, stdout=stream,
                           stderr=subprocess.STDOUT, start_new_session=True,
                           env={'PATH': '/opt/homebrew/bin:/usr/bin:/bin'})
try:
    time.sleep(0.5)
    assert new.poll() is None
    assert private_read(path, 16384) == original
    assert matching(record['tunnel_pid'], ' '.join(record['tunnel_command']),
                    record['process_started_at']['tunnel_pid'])
    assert process_command(record['tunnel_pid']) == ' '.join(record['tunnel_command'])
    updated = json.loads(original)
    updated['bridge_pid'] = new.pid
    updated['process_started_at']['bridge_pid'] = subprocess.check_output(
        ['ps', '-p', str(new.pid), '-o', 'lstart='], text=True).strip()
    updated['application_candidate'] = subprocess.check_output(
        ['git', '-C', str(root), 'rev-parse', 'HEAD'], text=True).strip()
    atomic_private(path, json.dumps(updated, indent=2) + '\n')
    active_window_url(root)
except Exception:
    if new.poll() is None: new.terminate()
    raise
print('桥已切换、当前窗口记录已核验；未请求官方API或更改购买开关。')
```
