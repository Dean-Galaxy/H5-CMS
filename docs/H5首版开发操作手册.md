1. 先推进工程基础、邮箱账号、四类后台权限、剧目上传与播放、Stripe 官方测试订阅、会员权益和取消续费。当前无需为了这些工作找投流同事要广告账号。

## 你需要听懂的几个词

| 词 | 大白话 |
|---|---|
| 本地环境 | 只在这台电脑上运行的开发版本 |
| 测试站 | 部署后可按授权从手机等设备访问的测试版本 |
| Sandbox 或沙箱 | 支付平台的练习环境，测试交易不转真钱 |
| 支付通知 | 支付平台主动告诉我们的服务器发生了什么 |
| 会员权益 | 这个用户是否能看付费内容，以及能看到哪一天 |
| 二次验证 | 输入密码后，再用通行密钥或验证器等方式核验身份 |
| 域名 | 网站门牌号 |
| 服务器 | 运行网站和业务程序的电脑 |
| 视频存储 | 专门保存和提供短剧文件的服务 |
| 备份恢复 | 真正把备份还原到另一套测试环境，再核对数据 |

## 第4项 接通 Stripe 测试订阅与会员权益

原定时间：2026-10-06 14:00—17:00。

**你具体怎么做**

1. 使用我交付的网站测试入口和测试账号，进入会员购买页面，核对套餐名称、价格、币种和扣款周期是否符合第1项决定。调价场景还要核对：持续中的老订阅保留约定常规价，新订阅使用调整后的价格；测试金额不代表正式售价。
2. 确认收银台属于测试环境后，按我给出的测试卡完成付款。付款返回网站后，检查会员到期时间和付费剧是否解锁。
3. 在 Stripe 同一测试环境查看对应付款或订阅，再和本站订单核对用户、金额、币种及状态。
4. 从本站会员中心进入管理订阅页面，测试取消。按已确认规则检查以后停止扣款、当期观看资格保留到正确时间。
5. 续费、续费失败和退款由我安排独立测试账号或测试订单演示。已确认的续费失败规则是：原已付费周期内仍可观看，到期且未续费成功时只可观看免费集，后续有效付款恢复其对应周期的权益。你核对结果，不需要理解支付通知代码。
6. 用独立测试账号核对首周优惠：第一次取消付款或付款失败后，再次购买仍能获得优惠；优惠付款成功后算已使用，即使之后取消续费或退款，下次新开订阅也按常规价。测试由我准备，你只需对照页面和订单结果。
7. 已有有效订阅时，再点击购买，应看到会员状态或管理入口，不应多开一份订阅。取消续费后，在尚未到期且原订阅仍可恢复时，点击“恢复自动续费”，先核对下一次扣款日期和原先约定的常规价，再确认恢复；核对到期日不变、恢复时没有多扣一笔。我会同时核对支付平台记录，并测试重复点击、付款处理中和续费失败时不会开出两份并行订阅。

**交给我处理**

## 测试付款时怎样填写

先让本对话确认收银台正在使用测试环境，再使用 Stripe 提供的测试卡。一个常见成功案例是卡号 4242 4242 4242 4242，未来的有效期，例如 12/34，三位测试安全码，例如 123。只在测试环境使用测试资料。失败、验证、续费及退款场景由我给出各自的测试步骤。[Stripe 测试说明](https://docs.stripe.com/testing)

付完款后至少核对三件事：Stripe 测试环境里存在对应付款；本站订单金额和币种正确；会员期限与播放权限正确。返回一个“成功”页面只证明页面打开了。续费测试可用 Stripe 的测试时钟推进账期，无需等到真实下个月。[订阅测试说明](https://docs.stripe.com/billing/testing)

Stripe 注册后可使用沙箱，正式收款另需验证业务并满足激活条件。公司资料和银行信息直接在官方后台提交，账号登录和双重验证由账号持有人完成。[账户设置说明](https://docs.stripe.com/get-started/account/set-up)
