# 01 本机使用说明

当前主工程已接收01–04本地组合，可以使用身份、内容后台、账务后台和观众页面。主环境尚未自动导入素材、价格或可信地区，官方Stripe与真实邮件未接通；缺少配置时会如实提示。本文主要说明本机启动和账号操作，观众网站及后续任务以[00-11接收单](handoffs/00-11-04修复接收与共同起点.md)为准。

## 打开和停止

在 Finder 打开 `/Volumes/KESU/H5/本地开发`：

| 你要做什么 | 双击哪个文件 | 应看到什么 |
|---|---|---|
| 启动 | `启动.command` | 数据库、网站、队列、定时进程启动，网站自动打开 |
| 看是否正常 | `状态.command` | 五项 checks 都为 true：web、queue、scheduler、database、http |
| 创建自己的首位负责人 | `创建负责人.command` | 依次输入姓名、邮箱和自己设定的密码；密码输入不显示 |
| 查看测试邮件 | `邮件预览.command` | Finder 打开本工作区的邮件目录 |
| 结束本次使用 | `停止.command` | 只停止本工作区服务，账号和数据保留 |

当前网站是 [http://127.0.0.1:8101](http://127.0.0.1:8101)，后台是 [http://127.0.0.1:8101/admin](http://127.0.0.1:8101/admin)。启动时显示的地址为准。首次从移动硬盘加载后台可能较慢；不要反复点登录。若 macOS 阻止打开命令文件，不关闭系统保护，使用下面的终端方式即可。

可以把这段复制到“终端”启动：

```sh
cd /Volumes/KESU/H5
python3 scripts/dev.py start
python3 scripts/dev.py open
```

状态与停止：

```sh
cd /Volumes/KESU/H5
python3 scripts/dev.py status
python3 scripts/dev.py stop
```

重启电脑、重新插入硬盘后，再运行启动即可。硬盘应仍挂载为 `/Volumes/KESU`；路径变了先让开发任务核对，不能把旧 `.runtime` 复制到另一套工程。拔硬盘前先停止。

## 观众怎么验证

1. 打开 [观众登录页](http://127.0.0.1:8101/identity/login)，点击“注册账号”，输入测试邮箱、称呼及至少12位且含字母和数字的密码。观众注册永远不会生成员工权限。
2. 点“我的账号”，应看到“待验证”和付款前需验证提示。浏览和免费试看不要求先注册。
3. 双击“邮件预览”，按修改时间打开最新 `.html` 文件，点击其中的验证按钮。应看到账号变成“已验证”。如果在另一个浏览器打开邮件，先用同一邮箱登录，再继续验证。
4. 验证链接 30 分钟到期、只用一次；重新发送后旧链接失效。重复或过期链接有明确错误提示和请求编号。可在账号页重发，60 秒内不能连续发送。
5. 首次验证前填错邮箱，可以在账号页输入正确邮箱及当前密码更正；已经验证的邮箱本阶段不能改。
6. 退出后点“忘记密码”，提交邮箱，再从本地最新重设邮件进入。密码改好后重新登录，旧会话失效。重设链接 30 分钟到期，不能重复使用。对于不存在的邮箱也显示相同受理提示。

“已验证”只证明本机身份流程通过，不会获得会员。账务模块已接入；首次付款仍要求邮箱验证，缺少有效价格或Stripe配置时明确拒绝，不生成付款成功或会员权益。

## 后台怎么登录

没有写在源码里的通用管理员密码。首位负责人由你在本机创建：

```sh
cd /Volumes/KESU/H5
python3 scripts/dev.py owner
```

进入后台，输入负责人邮箱和密码。首次出现“Set up two-factor authentication”时，点“Set up”（设置），用手机验证器扫描页面二维码，按页面输入当时的 6 位动态码，并自己保管恢复码。完成配置后点击“Continue”（继续），重新登录一次；在“Verify your identity”页输入新的 6 位动态码，点“Confirm sign in”（确认登录）进入后台。手机暂不可用时，“Use a recovery code instead”可改用一枚未使用的恢复码。后台不提供“记住登录”，空闲 30 分钟后需重新登录；同一个动态码和已用过的恢复码不能重放。首次设置与刚登录时如跨同一个 30 秒窗口，请等验证器显示下一个码。

负责人可以打开“员工账号与角色”：创建独立员工账号，选择角色；更改角色或取消“启用”后点该行“保存”。权限变化会撤销该员工的旧会话。不能停用或降级自己当前的负责人账号。每位员工首次登录都必须绑定自己的验证器。

| 角色 | 权限范围 |
|---|---|
| 负责人 | 全部后台权限，员工管理与角色分配 |
| 内容运营 | 全部内容的操作权限；不能改全站默认免费策略、价格、账务或投流配置 |
| 客服 | 以后通过具体客服请求查单、记备注，核实本人意愿后代取消续费；不能恢复、退款、改权益或全量导出 |
| 投流 | 已公开剧目信息，自己拥有或被分配的推广资源及聚合统计；没有观众个人信息权限 |

本次后三种角色还没有业务操作页面；服务器权限规则已建立并测试。对应模块接入后仍要验证真实数据归属，不能只靠隐藏菜单。

## 邮件、账号和服务要准备什么

**所有当前验证、找回邮件都只是本地预览，没有发往收件箱。** 本地预览目录里包含可登录或重设的链接，不要公开上传、发给无关人员或提交 Git。

你现在只需准备：自己使用的负责人邮箱和密码、手机验证器，以及恢复码的私密保存位置。测试观众可以自己注册。自动验收生成的随机 `@example.test` 观众仅为本机测试，不是正式账号；没有默认负责人。

以后真实邮件需要你选定发件邮箱/服务、能设置发件域名的账号，以及客服邮箱和值守人员。由 01/06 配置凭证、域名验证后，再分别验收验证信、重设信、垃圾邮件和失败情况；不能把“服务商受理”写成已送达。

真实域名、服务器、视频服务、Stripe 商户及 Meta/TikTok 资产分别由 00 汇总、02/03/05/06 接入。当前不需要你为这些缺项暂停本机验收，也没有采购、收费或对公网开放。

运行文件都在本项目自己的 `.runtime/`，密码配置在 `h5-platform/.env`，均不进入 Git。PHP 和 PostgreSQL 已按本机权限完成安装；当前没有等你确认的系统授权。若某项状态为 false，把状态结果和页面请求编号交给开发任务，不要删除数据库或重新初始化。
