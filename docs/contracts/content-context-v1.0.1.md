# Content 装载、地区与播放会话补充约定

共同契约 `1.0.1`，对应 02 提交的 `02-001` 申请（提交 `7551e7b`）。这是 00 管理的兼容补丁，不移动 `h5-foundation-v1`，不自动启用任何业务模块。1.0.0 的公开 HTTP 字段及已有 PHP 方法签名保持兼容；新增内部 RegionResolver 和 ResolvedRegion。

## 开发期怎样装载 Content

正式集成前，02 无需编辑根配置或从路由私自注册提供方。在自己的工作区实现 `App\Modules\Content\ContentServiceProvider` 后，可在自己未跟踪的 `.env` 明确设置：

```dotenv
H5_LOCAL_MODULES=content
H5_LOCAL_US_TEST_REGION=true
```

然后按本工作区脚本停止、启动，使 HTTP、队列和定时进程全部重读配置；使用过配置缓存的先清理本工作区缓存。禁止复制其他工作区 `.env`。主工作区本补丁默认两项均关闭，00 未启动 Content。

公共 LocalModuleRegistry 只在 local/testing 接受固定允许列表中的 `content`；配置的是模块名，不接受任意类名。缺实现、未知模块、试图覆盖已接收的不同提供方，或者在 staging/production 启用时都会明确拒绝启动，不静默回退。服务提供方不应产生启动时上传、发布或付款动作。

`ready` 只表示实际提供方已注册，不是“模块验收通过”。本地真实功能仍需 02 自测与 00 接收；正式集成后由 00 在公共 modules 配置中注册。独立 PHP 测试可在自己的测试初始化中显式注册真实提供方或有标记的测试替身，不能让测试替身进入普通运行。

## 统一地区来源

`RegionResolver::resolve()` 返回服务端创建的 ResolvedRegion：`country_code` 与 `source`。它不是给用户自行填写或选择的字段。

| 状态 | 返回 | 使用边界 |
|---|---|---|
| 未配置真实解析器，或无法可靠识别 | ZZ / unresolved | 地区未知，不能当美国或任意地区放行 |
| 明确启用本地美国场景 | US / local_us_test | 仅 local/testing、直接连接来源为 127.0.0.1 或 ::1 的 HTTP；控制台/队列不会自行假定观众在美国 |
| 将来真实受信解析器 | 实际国家代码 / trusted | 06 配置并验收可信代理、来源和解析适配后，才允许替换公共实现；目前未实现 |

公共实现不读取 query/body 中的地区，也不信任浏览器传来的 `CF-IPCountry`、`X-Country-Code`、`X-Forwarded-For` 等头。不得用语言、浏览器时区或付款币种推测国家。本地模式是人为指定的测试场景，04 必须明确显示“本地美国测试场景”，不能宣称真实地区识别通过。非 local/testing 启用该模式会拒绝启动。

02 的公开 HTTP 入口和 CatalogReader 使用同一 RegionResolver；后者不新增 region 参数，而是由提供方注入服务端解析器。调用 PlaybackAuthorizer 时只传解析所得国家代码。`ZZ` 时，内容读取返回 403 `REGION_BLOCKED`，不能用空列表掩盖无法识别；播放返回 `allowed=false/reason=REGION_BLOCKED`，许可字段全 null。提供方还必须核对剧目的有效授权国家和期限，不能仅凭传入 US 就放行。未装载 Content 时仍为 503，不因未知地区伪装成业务已实现。

后台编辑和发布计划按记录的授权范围/期限校验，不把定时进程缺少观众 HTTP 地区上下文解释为发布失败。只有面向观众的可见性和播放才使用观众地区。

## 播放会话：新开始与同集续签

| 04 的动作 | play_session_id | 02 的判定 |
|---|---|---|
| 第一次打开、刷新页面、切换分集 | null | 按当前免费 N、身份、会员、发布、地区和媒体重新判断，生成新会话 |
| 登录、登出或切换账号后继续 | null | 新身份重新判断，不能把游客/别人的会话当会员凭证 |
| 当前页面同一集连续播放，需要续签短期许可 | 当前服务端返回的 ID | 先核对同一分集和身份绑定、连续窗口，再检查最新权限；不能换集或无限延长 |

04 只在当前播放器内存保存会话，不存到 localStorage 或持久化观看进度。进度服务可能记录会话关联号，但不能把它当重新打开时的播放凭证。新页面/切集永远按 null 申请；不能通过 04 自行保留旧免费判断放行。

02 将会话绑定到站内观众 ID，或服务端匿名会话标识及分集；不以客户端自报身份创建绑定。未知/他人/其他分集会话统一 404，不透露记录。本人过期、已结束或媒体版本失效的会话用 409 `STALE_VERSION`；04 可按新播放申请重新判断，不能把 409 自动解释为免费或会员。

仅因免费 N 调整而保留当集的范围：

- 只有此前已按免费规则开始的同集连续会话，才保留本次免费判断。只取得许可尚未读取媒体，不算已开始；首次受控媒体读取仍检查当时权限，成功后记录服务端开始。这个技术标记不作为广告的“真实观看”事件。
- 使用已验证媒体时长建立有限窗口：默认自开始起 `2 × duration_seconds + 300 秒`。窗口不因续签、暂停请求或重复读取而重置；短期许可也不得超过该截止时刻。超过窗口重新按当前规则判断。该限制防止一张旧免费凭证永久保留，不改变免费 N 的已确认规则。
- 此例外只针对免费 N 变化。下架、地区或授权失效、媒体不可用、身份/对象不符仍拒绝；付费会话在续签和受控媒体读取时重查 03 的 MembershipReader。03 缺失或状态未知不能当会员有效，也不能自行给延期权益。
- 02 按媒体实现控制文件、Range、HLS 清单与分片，规定短期许可上限和撤销边界并测试；公开接口没有免检媒体入口。已交给浏览器并缓存的字节无法收回，不能宣称退款/下架能删除用户已取得的内容。

新增样例包含 `play_session_id=null`、同集续签 ID，以及客户端自报 region 被结构校验拒绝。身份绑定、首次读取、免费 N 更新、退款、下架、窗口/许可到期等真实业务测试仍由 02/03/04 完成；本补丁不提供假播放成功。

## D03 仍独立待定

服务器故障错过排期后的补发行为是业务决策，本补丁不默认 10 分钟窗口，也不选择自动补发。00 已向用户提出选项。未确认前，02 可以实现正常排期、防重、缺素材阻断和手动恢复的基础；遗漏时点的自动补发与相关异常验收保留待定，不能标为完整通过。
