# 事务邮件准备 mail-readiness-1

2026-10-31，00冻结仅Identity缺陷修复和SES SMTP配置准备，不是正式邮件/生产启用。沿邮箱密码登录与30分钟一次签名链接验证，不加六位码、不改普通密码/会员规则。SMTP/TLS/部署公共配置归00/06；01不修改根mail.php/Guard/依赖。

- 允许01仅修普通注册已建号后SMTP异常误报注册失败、忘记密码邮件异常破坏中性回应两项；重发的同类传输异常可一并安全503。使用已安装Symfony TransportExceptionInterface或01内部明确传输故障类型定位边界；不吞数据库/用户创建或其他Registered监听器业务错误，不把任意Throwable当邮件失败。SMTP超时只表示未确认，不声称未发送或自动重发。
- 普通注册账号一旦提交，不因传输失败回滚/重注册；保留未验证事实与必要正常登录/可恢复重发。可复用现AuthResponse形状，仅在已提交账号且邮件未确认时引导现有account页并显示中英“账号已创建，验证邮件发送未确认；可稍后重发，不必重新注册”，不强改其他成功return_to，也不增加公共响应字段。仅01内flash/现view接线，JS无须变化则保持。未验证不可获得已验证/会员/员工权限。
- R1测试条款及preview限制完整保留，不能因真实SMTP绕开；原R1成功/失败、目的及普通正常注册现有行为复用，测试不扩大R1异常集合。正式服务条款/政策/收据另核，不能把本机文案复用上线。
- forgot仅捕获真实发送通道异常并维持已存在/不存在/节流等同一中性accepted形状及不承诺送达的文字；保留现接口/密码broker节流/token重置行为，日志只安全故障类别及请求号，禁止邮箱/口令/验证重设token/SMTP异常正文。重发可安全MAIL_DELIVERY_UNCONFIRMED/503，不自动连发；不吞其他故障或改nonce事务原语义。
- 关闭条件：01隔离测试注入邮件传输异常，普通账号仍只1、未验证且可正常登录/重发；创建/DB或非邮件事件异常不能被误当成功；正常发送、R1preview限制及找回中性故障/节流必要边界通过。只跑新增/直接受影响Identity测试，旧reset单次/撤会话等未改证据复用，开发不发真实邮件、不操作现有人工库。
